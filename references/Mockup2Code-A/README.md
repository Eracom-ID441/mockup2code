 de https://coolors.co/. 
 Tandis que celui de la section "mirandalandber" a été supprimé car jugé alors inutile. Si les titre de cette  sections devaient être ammenée a rediriger ailleurs l'utilisateur, la couleur sera opposé aux gris.

 - L'attribut loading="lazy" est appliqué.
